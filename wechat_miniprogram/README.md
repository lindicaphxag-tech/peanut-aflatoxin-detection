# 微信小程序工程（花生霉变视觉检测）

用 **微信开发者工具 → 导入项目** 选择本目录即可。

## 导入后必须做的一步

右上角 **详情 → 本地设置** → 勾选
**「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**

否则所有 `http://127.0.0.1:5000` 的请求都会被拦截，首页显示"推理服务未连接"。

## 后端地址

改 `config.js` 里的 `API_BASE`（只有这一处）：

```js
const CONFIG = {
  API_BASE: 'http://127.0.0.1:5000',   // 真机调试改成电脑局域网 IP，例如 http://192.168.1.10:5000
  REQUEST_TIMEOUT: 20000,
}
```

## 目录

| 文件 | 作用 |
|---|---|
| `app.js` / `app.json` | 应用入口、四个 tab 页配置 |
| `config.js` | 后端地址（唯一需要改的地方） |
| `pages/index` | 检测页：拍照 / 相册 / 批量，显示三分类概率 |
| `pages/history` | 检测档案：本地缓存、统计、详情、清空 |
| `pages/knowledge` | 黄曲霉科普、国标限量 |
| `pages/about` | 关于页：实测指标 + 局限说明 |
| `data/metrics.js` | 关于页上的指标数字来源 |
| `custom-tab-bar` | 自定义底部导航 |

完整跑通步骤见上级目录 `使用说明.md`。
