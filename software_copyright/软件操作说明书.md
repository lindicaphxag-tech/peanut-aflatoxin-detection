# 坚果黄曲霉实时检测系统 V1.0 软件操作说明书

## 1. 软件概述
本软件是面向消费级智能手机开发的坚果类黄曲霉快速检测应用，支持HarmonyOS和Android双平台。软件集成近红外三波段图像处理算法与LightGBM轻量化机器学习模型，无需专业实验室设备，用户通过配套的滤光片手机壳拍摄花生样本，即可在3秒内完成霉变检测，输出正常/霉变判定结果与置信度，同时支持检测历史本地存储与查看。

## 2. 运行环境
### 2.1 鸿蒙端
- 操作系统：HarmonyOS 4.0及以上
- 硬件要求：支持后置多摄像头模组的华为/荣耀智能手机，内存≥4GB
- 存储要求：剩余空间≥200MB

### 2.2 Android端
- 操作系统：Android 8.0及以上
- 硬件要求：支持后置摄像头的智能手机，内存≥4GB
- 存储要求：剩余空间≥200MB

## 3. 功能模块
软件共分为三个核心功能模块：
1.  **检测拍摄模块**：提供标准化拍摄引导，支持相册图片上传与实时拍摄，自动完成三波段图像采集、预处理与特征提取
2.  **本地推理模块**：端侧运行LightGBM树模型，无需云端联网即可完成霉变概率计算，保护用户隐私
3.  **历史记录模块**：本地加密存储所有检测记录，包含检测时间、样本缩略图、检测结果与置信度，支持按时间倒序查看

## 4. 操作说明
### 4.1 首次启动
用户安装软件后首次启动，弹出权限申请弹窗，授予相机与存储权限后即可进入主界面。

### 4.2 开始检测
1.  将配套滤光片手机壳安装到手机上，将待测花生样本放置在遮光罩下方
2.  点击主界面「开始检测」按钮，软件自动完成三波段图像拍摄（或从相册选择已拍摄的检测图像）
3.  拍摄完成后软件自动进入分析状态，进度条显示分析进度，约3秒后输出检测结果
4.  结果页显示：
    - 正常状态：绿色提示文字"花生状态正常"，附带置信度数值
    - 霉变风险：红色提示文字"存在黄曲霉污染风险"，附带霉变概率数值
5.  检测完成后自动将记录保存到本地数据库

### 4.3 查看历史记录
1.  点击主界面「查看检测历史」按钮进入历史列表页
2.  列表按检测时间倒序排列，每条记录显示检测时间、结果状态、置信度
3.  点击任意记录可查看完整的检测图像与详情

### 4.4 注意事项
- 检测结果为快速筛查参考，确诊结果请以实验室化学检测为准
- 使用时请确保遮光罩完全覆盖样本，避免环境自然光干扰
- 模型会通过后续OTA升级持续优化检测精度

## 5. 技术特点
1.  全端侧推理：所有计算在本地完成，无需上传用户图像，保护隐私
2.  轻量化模型：LightGBM模型体积<1MB，单张检测耗时<200ms
3.  双平台兼容：同一套算法核心同时适配鸿蒙与Android系统
4.  离线可用：无网络环境下可正常使用全部检测功能
