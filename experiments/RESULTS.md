# 公开花生光谱数据实验报告

## 目标与边界

本实验检验公开花生高光谱表格上的五类数字标签能否被分类，是独立的数据流程测试。它不测试本项目的 Android 或鸿蒙图片推理，不测量黄曲霉毒素含量，也不能用于食品安全判断。

## 数据与方法

- 数据：[Peanut-seed](https://github.com/wuqingsongwj/Peanut-seed) 的 `peanut.xlsx`；来源论文：[Wu 等，2022](https://doi.org/10.3389/fpls.2022.1047479)。
- 文件 SHA-256：`5ae0b3ae5175e5adebfb5091045cacb02f05c9e50593ac0a7cf4fadd06f28866`。
- 表格共 2,200 行，每行 236 个数值输入和 1 个数字标签。标签 1–5 的数量依次为 400、400、400、400、600。
- 发现 120 条重复光谱，重复行的类别一致。按精确相同的光谱分组，采用分层五折分组划分的第一折作为测试集；随机种子 42，训练 1,760 行、测试 440 行。相同光谱不会跨训练集与测试集。
- 比较多数类别基线和固定参数的 LightGBM；未在该测试集上调参。

## 结果

| 方法 | 测试准确率 | 宏平均 F1 |
|---|---:|---:|
| 多数类别基线 | 27.27% | 0.0857 |
| LightGBM 光谱基线 | 94.09% | 0.9368 |

LightGBM 混淆矩阵如下，行是真实数字标签，列是预测数字标签，顺序均为 1–5：

```text
75   1   3   1   0
 0  78   0   0   2
 1   0  76   3   0
 3   7   2  68   0
 0   1   0   2 117
```

## 限制

1. 表格没有提供数字标签与具体类别的映射，不能将某一类召回率称为霉变或毒素检出率。
2. 论文描述 235 个光谱波段，表格却有 236 个数值输入列；额外一列的含义未获确认，存在潜在信息泄漏风险，结果只能作为探索性数据流程测试。
3. 没有样本、批次、采集场次或设备分组标识。虽然完全重复的光谱已分组，仍无法排除同批次或相似样本跨集合，不能据此宣称跨批次泛化。
4. 原论文描述的实验涉及多品种和霉变样本，但公开表格没有逐样本毒素浓度，因此无法评估浓度预测、法定限值判别或食品安全。
5. 手机端是图片输入且使用不同的 16 维近似特征，本实验是独立的 236 列光谱输入；实验分数不能用于描述手机应用或原有移动端模型。

复现实验的脚本位于源码包的 `experiments/public_spectra_baseline.py`，机器可读结果见配套 JSON。该公开数据未随源码包再分发；请自行从上述来源获取。
