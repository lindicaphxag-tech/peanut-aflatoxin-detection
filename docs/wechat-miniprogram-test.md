| 编号 | 用例 | 触发方式 | 预期 | 实际 | 结论 |

## 3. 缺陷记录（全部已修复）

| 编号 | 缺陷 | 影响 | 原因 | 修复 |
|---|---|---|---|---|
| D-01 | 后端启动即崩：`UnicodeEncodeError: 'gbk' codec` | 服务完全不可用 | Windows 控制台默认 GBK，打印 emoji 字符失败 | 启动时 `sys.stdout.reconfigure(encoding='utf-8')`，并移除易崩字符 |
| D-02 | 批量检测把霉变记成"正常" | 统计错误 | 用 `data.result === '霉变'` 判断，而模型返回"发霉长毛/发霉不长毛"，永不匹配 | 改用 `class_index > 0` |
| D-03 | 自定义 tabBar 文字竖排成一列 | 导航不可用 | 组件样式隔离，`display:flex` 未生效 | 改用原生 tabBar + 自绘 81×81 PNG 图标 |
| D-04 | 结果卡滑不出来（被裁掉） | 用户看不到检测结果 | `.container` 上 `overflow: hidden` 裁掉了超出一屏的内容 | 容器改为可滚动，横向溢出交由 `page { overflow-x }` |
| D-05 | 检测完成后首页"最近一次"不刷新 | 信息陈旧 | `loadLast()` 只在 `onShow` 调用 | `detect()` 与批量完成回调补调 `loadLast()` |
| D-06 | "无法判断"时判定大字仍为绿色"正常" | 语义矛盾 | 判定样式只按 `classIndex` 上色 | 增加 `v-hold` 置灰态，副标题改为"信心不足，建议重拍" |
| D-07 | 批量缩略图的置信度被标签遮住 | 信息不可读 | 两个绝对定位元素叠在底部 | 合并为单个底部渐变浮层 |
| D-10 | 全屏浮层被压成普通流式块 | 新增的全局 `z-index` 规则给所有直接子元素加了 `position: relative`，连带覆盖了浮层的 `fixed` | 规则排除 `.analyzing/.poster-mask/.modal`，并给弹层内部加 `z-index` |
| D-09 | 有记录时仍显示"还没有记录"空态 | 筛选用的空态与列表空态条件串成了 `wx:else` 链 | 空态改回独立的 `wx:if="{{!list.length}}"` |
| D-08 | 注释文字对比度不足（3.32:1） | 小字难读，不达 WCAG AA | `--muted-2` 取色过暗，页脚还有硬编码 `#4e463b`（约 2.2:1） | 提亮到 `#8e8476`（≥4.53），页脚改用令牌 |

**其他记录（非缺陷）**：自动化截图在同一 IDE 会话内多次调用会静默失败，属于开发者工具限制；测试流程固定为"重启 IDE → 单次截图"。

## 5. 验收结论

- 用例 **25 项**（16 条功能 + 5 条边界 + 1 条数据导出 + 1 条可访问性 + 1 条筛选排序 + 1 条加载态），**通过 25 项**，无未通过项；
- 缺陷 7 项，**全部修复并回归验证**；
- 端到端链路（小程序 → HTTP → Flask → ResNet18 → 结果渲染）实测打通；
- 主包体积 100 KB，远低于限制；
- 结论：**满足结题演示与试用要求**；正式上线仍需满足主体认证、备案域名与 HTTPS（见 `使用说明.md` 第四节）。
